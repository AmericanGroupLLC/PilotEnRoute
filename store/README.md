## Disclosures

- **Apple App Privacy:** every data type collected, whether it is linked to the
  user, and whether it is used for tracking.
- **Google Data Safety:** the same, plus whether data is encrypted in transit
  and whether the user can request deletion.
- **Content rating:** questionnaire on both stores.

Answer these from what the code actually does. A disclosure that does not match
observed network traffic is a rejection, and later a removal.
