2. DEVICES AND OS VERSIONS TESTED
Automated tests run on every build: iPhone 17 Pro Max and iPad Pro 13-inch simulators on iOS 26, and a Pixel Android emulator on API 34.
Each release is also installed and launched on those targets, so a
build that cannot start never ships.

3. WHAT THIS APP DOES, AND FOR WHOM
PilotEnRoute is a study and record-keeping companion for pilots and student pilots. It is a training tool for use on the ground — not an avionics or navigation product.

Intended audience:
FAA study, logbook & E6B

4. SETTING UP AND REACHING THE MAIN FEATURES
The app opens on a sign-in screen. An account is optional; the main features can be reached without signing in.

5. EXTERNAL SERVICES USED
- Supabase — account and data storage
- Google AdMob — advertising
- Google Sign-In — authentication
- Sign in with Apple — authentication
- HTTPS requests to the app's own endpoints
- Free public data APIs, no account: OpenSky Network (live traffic), adsbdb.com (aircraft lookup by registration), U.S. Bureau of Labor Statistics (career median pay), aviationweather.gov (weather)

6. REGIONAL DIFFERENCES
The app ships 12 languages (Arabic, Chinese (Simplified), English, French, German, Hindi, Italian, Japanese, Korean, Portuguese, Russian, Spanish). Features are identical in every region.

7. REGULATED INDUSTRY OR THIRD-PARTY MATERIAL

The app is not in a regulated industry and carries no licensed third-party material. All content, artwork and copy are the developer's own.
