# Fastlane - PilotEnRoute

Generated by `store-kit/build_app.py`. The listing copy lives in
`fastlane/metadata/`; edit `store-kit/apps/pilotenroute.json` and regenerate rather
than editing the `.txt` files by hand.

## Lanes

| Lane | What it does |
|---|---|
| `fastlane ios test` | Runs `flutter test` |
| `fastlane ios build` | `flutter build ipa --release` |
| `fastlane ios metadata` | Pushes the App Store listing text only |
| `fastlane ios release` | test + build + upload binary, metadata, screenshots |
| `fastlane android build` | `flutter build appbundle --release` |
| `fastlane android metadata` | Pushes the Play listing + images only |
| `fastlane android release` | build + upload AAB to the internal track as a draft |

## Required environment

Nothing secret is committed. Set these before running a release lane:

```bash
export ASC_KEY_CONTENT=$(base64 -w0 AuthKey_XXXXXXXX.p8)   # SECRET
export ASC_KEY_ID=XXXXXXXX
export ASC_ISSUER_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
export APPLE_TEAM_ID=TLH7Z3G27A
export PLAY_JSON_KEY_FILE=/path/to/play-service-account.json   # SECRET
```

## Screenshots

`fastlane/screenshots/en-US/` (Apple) and
`fastlane/metadata/android/en-US/images/phoneScreenshots/` (Play) are **not**
generated - they need a real device or simulator. Run
`./tools/capture_store_shots.sh` on a macOS machine with Xcode installed.
